# Bundled GME SDK assets

The repository owner explicitly requested that the SDK assets needed by the
music adapters be included in the public repository and asserted distribution
rights for this project. These are vendor SDK payloads, not part of the
project's `ISC` package metadata.

| Adapter | Included files | SDK version/source |
| --- | --- | --- |
| Windows native | GME headers, import library, and runtime DLLs | GME 2.9.15 files already present in the project workspace |
| Linux native | GME headers, x86-64 runtime libraries, and compatibility-stub sources | GME 2.9.15 files already present in the project workspace; runtime compatibility files are generated by `build_linux.sh` |
| Android / Redroid | `gmesdk.jar` and native libraries for arm64-v8a, armeabi-v7a, x86, and x86_64 | Tencent GME Android SDK 2.9.17, downloaded 2026-10-07 |
| Web H5 | Browser `WebRTCService.js` bundle | Tencent GME Web SDK 2.9.10.14, downloaded 2026-10-07 |

The Android build packages the x86_64 libraries for Redroid by default; other
ABI libraries are retained in the repository SDK bundle. The Linux native SDK
libraries are the x86_64 files used by this adapter and have the compatibility
patch marker expected by the included build helper.

The Android and Web SDK archives did not contain files named `LICENSE`,
`NOTICE`, or `COPYING`. This inventory records the owner's instruction and the
package contents; it does not claim that Tencent's SDK is covered by the
project's `ISC` metadata. GME AppID/keys, YelloTalk tokens, adapter tokens,
Azure/Groq credentials, and Android signing inputs are not included; supply
them through local configuration or environment variables only.
